# 🌟 Dream Events – Event Management & Booking Platform

**Dream Events** is a full-stack event management and booking platform designed to make event planning easier. Customers can explore decoration services, compare packages, and submit event bookings online.

The platform includes a responsive **customer-facing website** and a secure **Admin Dashboard** for managing bookings, packages, services, testimonials, gallery images, and business information.

---

## ✨ Features

### 👤 Customer Portal

* 🏠 Responsive and modern home page
* 🎉 Browse event decoration services
* 📦 Explore Bronze, Silver, and Gold packages
* 💰 View package pricing and details
* 📝 Multi-step event booking system
* 📎 Upload design inspiration and layout files
* 🖼️ Categorized event gallery
* ⭐ Customer testimonials
* 📍 Google Maps integration
* 📱 WhatsApp and social media integration
* 📧 Contact and enquiry options

### 🔑 Admin Dashboard

* 📊 Booking and revenue analytics
* 📋 View and manage customer bookings
* 🔄 Update booking status
* 📦 Manage event packages
* 🎯 Manage service categories
* ⭐ Manage customer testimonials
* 🖼️ Upload and manage gallery images
* 📞 Manage business contact information
* 🔐 Secure admin authentication using JWT

* **React Hook Form**

* **Java 21**

* **Spring Security**
* **JWT Authentication**
* **Spring Data JPA**
* **Hibernate**
* **PostgreSQL**
* **Springdoc OpenAPI / Swagger**
* **Cloudinary Java SDK**
* **JavaMailSender / SMTP**
